## 재계산 규칙의 단계

양식 수식대로 다시 계산했는데 값이 다르면(수식 훼손·값 덮어쓰기) ERROR, 해석 차이가 있을 수 있으면 WARNING.

| ID | 단계 | 내용 |
|---|---|---|
| A-2-2-RECALC | WARNING | A-2-2: 선택한 값이 n ≤ N-3 계산(n = 연차별 전공의 정원 중 최댓값)과 다릅니다. 이동수련자가 있으면 다를 수 있으니 확인하세요. |
| B-5-RECALC | ERROR | B-5: 양식 수식(진료 실적 ÷ 전공의 총 정원)으로 계산한 값과 다릅니다. 수식이 지워졌거나 값을 직접 고쳤는지 확인하세요. |
| C-4-RECALC | ERROR | C-4: 양식 수식(논문 점수 ÷ 전체 시트의 총 전문의 수)으로 계산한 값과 다릅니다. 수식이 지워졌거나 값을 직접 고쳤는지 확인하세요. |
| B-4-3-RECALC | ERROR | B-4-3: 양식 수식(논문 점수 ÷ 전공의 총 정원)으로 계산한 값과 다릅니다. 수식이 지워졌거나 값을 직접 고쳤는지 확인하세요. |
| B-2-3-RECALC | ERROR | B-2-3 a/b: 양식 수식(외부 학술대회 총 참석 횟수 ÷ 10/1 기준 실제 근무 전공의 수)으로 계산한 값과 다릅니다. 수식이 지워졌거나 값을 직접 고쳤는지 확인하세요. |
