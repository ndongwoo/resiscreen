# 재현율 평가 (B~E 평가 전·후 쌍)

F 쌍은 평가전 파일이 실제 제출본으로 확인되지 않아 제외(M1 보고서 5절).

> **주의: 표본 내 평가입니다.** B-2-3-KIND·B-2-3-DUP 규칙은 이 표의 B·C병원 수정 사례를 보고 만든 규칙이라, 아래 재현율은 그 사례를 다시 맞힌 것에 가깝고 일반화 성능을 뜻하지 않습니다. 일반화 성능은 추가 병원 자료(약 20개 병원)를 받아 규칙을 고정한 상태로 다시 재겠습니다.
