# 오탐 검토: A병원과 B~E 평가 후 파일(심사 통과본)에 남는 ERROR·WARNING (2026-11-26)

> 공개용 판: 익명화 파일의 셀 원문 값(이름·제목·저널명·숫자 값)은 위치만 남기고 지웠다. 원문이 들어간 원래 판은 비공개 `docs/private/`에 있다.

평가 후 파일은 학회 심사를 거친 파일이다. 여기 남는 결과는 다음 넷 중 하나로 분류했다.

- **진짜 문제**: 실제 오류·누락이다. 심사에서 넘어갔을 수 있다.
- **진짜(영향 없음)**: 규칙이 말하는 사실은 맞지만 값이나 점수에는 영향이 없다.
- **심사 흔적**: 심사자가 평가 후 파일을 고치면서 생긴 결과다. 병원이 제출 전에 이 도구를 돌리면 나오지 않는다.
- **오탐 의심**: 규칙이 틀렸거나 너무 넓다.

셀 값과 인명은 적지 않는다. 기준은 규칙 34개(오탐 1건 수정 후)다.

## 요약

| 분류 | ERROR | WARNING |
|---|---|---|
| 진짜 문제 | 3 (D 2, E 1) | 12 |
| 진짜(영향 없음) | 0 | 9 (B DM6, C S6:Z6) |
| 심사 흔적 | 1 (C DS6) | 8 |
| 오탐 의심 | 0 | 0 (C E40 1건은 규칙 수정으로 해소) |

- 심사 통과본에 남은 ERROR 4건 가운데 3건이 진짜 문제다. 나머지 1건은 심사자가 남긴 흔적이다.
  - D의 B-5-3 수식 삭제와 FK6 글자 입력은 점수에 직접 영향을 주는데 심사에서 넘어갔다. 제출 전 점검이 도움이 되는 사례다.
- '진짜(영향 없음)' 9건(수식 자리에 같은 값 입력)은 WARNING으로 두는 것이 맞다고 본다. 이렇게 덮어쓰면 다음 해 양식을 재사용할 때 수식이 사라진다.
- 표본이 5개 파일이라 오탐률은 추가 병원 자료로 다시 재야 한다.
