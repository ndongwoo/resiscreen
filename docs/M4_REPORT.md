## 1. 한 일

### 엔진 `src/engine/biblio/`
- `match.ts`: ResiReview `engine/bibliography*.py`를 TypeScript로 다시 작성.
  - 제목: 정규화(마크업·기호 제거, NFKC, 소문자)와 Python `difflib.SequenceMatcher.ratio` 이식. 5개 사례에서 Python 값과 소수 12자리까지 같다.
  - 저널 일치: ISSN, 핵심명, ISO 약어.
  - 정식 출판일: 인쇄일 → 권호 발행일(선출판 제외) → 온라인 전용 권·쪽/논문번호 순.
  - Epub 판별, 쪽 수 계산.
- `crossref.ts`, `pubmed.ts`: Crossref(DOI·제목 검색)와 PubMed(esearch 제목·DOI → efetch). PubMed에서 논문 유형과 EqualContrib 수를 읽는다. 외부로 보내는 것은 DOI 또는 제목, 연락처(mailto)뿐이다.
- `throttle.ts`
  - 모든 요청의 시작 간격을 0.5초 이상으로 둔다(초당 2건 이하, 설정값). Crossref 동시 요청은 2개까지.
  - 네트워크 오류는 429일 수 있다고 보고 지수 백오프(1·2·4초)로 3회 다시 시도한다. 그래도 실패하면 '확인 불가'로 처리한다. 시간 초과는 15초. 404는 '없음'으로 처리하고, 400은 다시 시도하지 않는다.
  - 취소(AbortSignal)를 지원한다.
- `client.ts`
  - DOI 열이 있으면 DOI를 먼저 조회하고, 없으면 제목으로 검색한다.
  - 국내지는 Crossref를 먼저 조회하고, 확신 있게 맞으면 PubMed는 건너뛴다. 해외지는 둘 다 조회한다.
  - 확신도 기준: 제목 유사도 ≥ 0.90, 연도 일치, 저널 일치. 기준에 못 미치면 '자동 확인 불가(후보 표시)'로 낸다.
- `cache.ts`: 캐시 인터페이스. 메모리용과 IndexedDB용(브라우저·Worker)이 있고, Node 파일 캐시는 `src/cli/filecache.ts`. DOI·제목 기준이고 TTL 30일, 공개 서지 정보만 저장한다.

   - 그래서 Crossref는 초당 1.5건·동시 1개(`biblio.source_rps`), PubMed는 초당 2건으로 정했다.
   - 연속 실행에서는 그래도 429가 가끔 나온다. 재시도로 모두 회복했고 실패는 0건이다.
